# PL / BT display volumes

85 real snapshots per model, z = 35.216929 → 6. Native 256³ → 64³ volume means of linear physical fields. Little-endian float32, x-fastest.

Tb is available for 44/85 PL and 68/85 BT snapshots after source-temperature and range checks. This is not physical certification. Flagged frames are withheld individually, with reasons in each manifest. Source arrays are never clipped, substituted or overwritten. Original HDF5 and higher display resolutions stay on HPC.

Display assets are read through raw.githubusercontent.com and excluded from the Pages artifact.
