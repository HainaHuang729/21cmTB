# PL / BT display volumes

Version `pl-bt-v1`: 85 real snapshots per model, z = 35.216929 → 6.
Native 256³ → 64³ volume means of linear xH and density contrast. Little-endian float32, x-fastest. Not the legacy independent 64³ simulation.

Tb is deliberately omitted pending investigation of extreme finite source-cache values. Original HDF5 and 128³/256³ arrays stay on HPC.

These derived data are read on demand through raw.githubusercontent.com and excluded from the GitHub Pages artifact. Manifests include units, statistics, checksums and source simulation identifiers. No private filesystem paths are published.
