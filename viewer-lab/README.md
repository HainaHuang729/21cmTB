# 21cm 体渲染实验室

独立、可直接运行的 WebGL2 实验页及数值切片浏览器。没有修改主页面或线上 Viewer，没有构建步骤和第三方运行依赖。

## 运行

在此目录运行 `npm start`，打开 `http://127.0.0.1:8766/`。也可以用任意静态服务器通过 localhost 或 HTTPS 打开；数据 SHA-256 校验依赖安全上下文，不能直接双击 HTML 文件运行。

页头“切片库”打开 `http://127.0.0.1:8766/atlas.html`。本地 `atlas-data` 是指向仓库已有 `../web_data` 的相对符号链接，不纳入 Git，也不复制约 1 GB 数据。首次克隆后，在此目录执行 `ln -s ../web_data atlas-data` 即可通过 Python 静态服务器读取。部署到仓库子路径时直接复用 `../web_data/`；两者均不可用时，浏览器改用固定上游版本的公开数据，需要网络。

空腔剖切样品单独位于 `http://127.0.0.1:8766/cavity.html`，未接入主页面。开放 PL / BT 两个 250 cMpc 模型，各保留完整 85 个红移位置；PL 的三个场均发布完整 85 帧；BT 中性氢/密度完整，亮温发布 68 帧；三个阶段按钮保留为代表快照的快捷入口。在同一相机下可切换阈值界面和原体显示。界面通过原始 64³ xH 的三线性重建、射线阈值求交与五次二分细化形成；前侧斜面可调，开放切口以赭红切缘标记，不填充遮挡内部的大平面。表面梯度光照结合五方向、每方向三点的局部环境遮蔽，以及八步方向阴影；它们是显示近似，不是再电离辐射输运。弱透明体积保留少量场背景，右侧原值切片与全盒均值不受阈值、剖切或光照影响。没有人工补造空间细节或时间插值。拖动旋转、滚轮缩放、方向键、加减键及 Home 均可用，画面按窗口比例调整取景。

固定底栏提供红移滑块、上一帧/下一帧和播放/暂停。滑块按真实快照的时间顺序从高红移移向低红移，显示实际 z 与帧序号；不是连续红移插值，也不是等宇宙时间步长。帧间隔可选 0.12、0.25、0.6、1.2 秒，默认 0.12 秒。首次进入会预载当前模型当前场的已发布序列，再后台缓存其他模型与物理场；点击播放会等待当前序列准备完毕，等待期间可点“取消准备”。底栏显示全部 493 个场数据体的缓存进度及当前场的内存预载进度，失败项可重试。下载与校验不再发生在正常播放的逐帧路径中。

两个模型共 170 个 xH、170 个密度和 153 个亮温数据体（493 MiB）已在本地发布，`python3 scripts/cache-data.py --all-sample` 可按固定版本补齐、校验和修复，支持中断后重跑。浏览器另用 Cache Storage 按固定提交与文件 SHA-256 保存原始字节，刷新后可复用；读回时仍校验哈希、数值和统计，损坏缓存会删除并重新读取来源。浏览器空间不足或禁用缓存时，保留本地文件回退及明确提示。只有通过核验的帧才算准备完成。

当前模型当前场的全部已发布原始数据常驻内存，其他场最多保留八个 LRU 数据体；切换物理场后重新从持久缓存预载新序列。Web Worker 提前计算接下来两帧的原值梯度，只保留最近四个梯度体（最多 16 MiB）；传输副本不分离或修改经过校验的原始数据。GPU 复用一份标量纹理和一份梯度纹理，逐帧上传内容，不重复创建纹理。播放不跳过真实快照，实际速度受渲染耗时影响，不添加伪造的过渡帧。

普通逐帧切换保持相机、物理阈值、剖切与光晕参数，不按每帧范围重新归一化。暂停会取消尚未完成的显示切换，后台缓存继续；拖动红移滑块、阶段跳转、切换物理场或页面隐藏会停止播放，播放到末帧自动停止，再点“重播”从首帧开始。均匀的真实末帧会明确提示没有空间界面。地址中的 `model`、`field` 和 `z` 记录所选模型、物理场及真实红移，包含审核缺口；重新打开时选择最接近的真实红移。

样品默认新增“电离辉光”显示，可与“界面剖切”“原体显示”在同一相机和快照下切换。原始 xH 的中心差分独立存为 64³ RGBA 梯度纹理，原始标量不作修改；界面附近的窄值带以真实梯度调制透明度，均匀场没有虚构的发光前沿。半透明界面按射线前后合成，轮廓角度与距离调节显示亮度，最多累计八次界面交叉。青色辉光及暖色切缘都是结构强调，不代表模拟输出的光度、电流或已解析的物理电离前沿。选择性 Bloom 采用 HDR 场景、亮部提取、四分之一尺寸的横纵高斯模糊和 ACES 近似色调映射；不支持浮点颜色缓冲时采用 RGBA8 编码回退。底栏“光晕强度”可从零开始调节，原值切片与全盒均值保持不变。

页头可切换 PL / BT 模型及三维中性氢、密度和亮温。各模型各场保存显示参数，切换时保持同一真实红移，方便比较；不宣称模型之间逐体素相位匹配。`cavity.html?field=density` 直接打开金色密度网络：在插值原始 δ 后作 `log(1 + max(δ,0)) / log(4)` 显示映射，用稀疏体积合成表现较弱的青色结构和高密金色节点；它没有人工添加粒子、恒星或几何连线。阈值仍以原始 δ 输入。“界面剖切”另行展示该阈值的等值面，原体显示和原值切片保持固定线性色标。

`cavity.html?model=pl&field=brightness_temperature` 打开同组 250 cMpc 冷暖亮温。PL 已用相同初始条件和物理参数完整重算，修复 Python 驱动在请求输出节点跳过温度与电离状态递推的问题，三个场均可播放全部 85 个真实红移。原始 256³ 范围、温度、完整性及读回检查、演化递推链、独立单目标对照和 64³ 均值守恒/轴顺序检查均通过；[修复记录与校验凭据](science/pl-thermal-repair/README.md)可追溯。BT 保留原缓存，本次没有重算；其 17 帧审核段仍为 z=24.865–17.841，以红色标记。缺口没有场文件，页面不下载、不复用旧图像，也不补造插值；原值切片与均值清空，播放到缺口暂停，可手动跳至前后有效片段。已发布状态仅代表源温度与数值范围筛查通过，不构成物理认证。

蓝色为负亮温吸收，橙红为正亮温发射，零值透明；显示阈值使用 `|δTb|` 的 mK 原值，两个模型共用固定 [−150,40] mK 色标。阶段按钮从已发布快照选择平均吸收最强、平均发射最高、接近平均 xH=0.2 的帧；默认发射峰值为 PL z=7.966 / BT z=14.765。阈值求交使用插值原值的绝对值，梯度按符号修正显示方向，原始缓冲与原值统计不作变换。辉光只是可视化表达。Ts、Tk 当前只在二维切片库发布，未伪造三维重建。

`npm test` 检查打包快照的 SHA-256、网格数据、统计量、阶段选择、带符号物理场、播放顺序与异步暂停、缓存损坏修复/共享请求/内存上限/梯度工作线程、透明度曲线、三维坐标和切片拾取，以及真实 BPL/PL 五场解压、量化、坐标和异常数据拒绝。Node.js 22 或更新版本可运行测试；切片测试读取仓库已有 `web_data/`。

## 范围与真实数据

- PL / BT 250 cMpc 系列各 85 个 coeval 快照；PL 三个场全部开放，BT 开放全部 xH、密度及部分亮温；64³ 网格来自原始 256³ 线性值的 4³ 体积平均。
- PL 100 cMpc 系列是另一套原生 64³ 模拟，共 19 帧，开放 xH、密度和带符号亮温。它使用不同的随机种子、盒长和物理参数，不能视作 250 cMpc 系列的低分辨率版。基础实验室仍要求物理场覆盖完整序列，因此在该页面开放完整的 PL 250 cMpc 亮温，禁用不完整的 BT 亮温；辉光样品单独支持带缺口的序列。
- BT、100 cMpc 系列及二维切片来源固定于上游提交 `7daaaca68ac6df4f9ccd95fbb1bbb16ecc042fc0`。PL 250 cMpc 使用本次重算后的独立固定版本，具体提交见 `data.js` 的 `REVISION`；清单记录原始模拟身份、IC 指纹、驱动/C 二进制校验值与独立对照差异。原始 256³ HDF5 与三维 Ts/Tk 仍保留在集群。
- `data/` 当前注册 518 个经过校验的真实场文件（518 MiB），包含辉光样品的全部 493 个场数据体，以及独立 100 cMpc 系列的 25 个缓存。另保留 214 个已被替代的旧 PL 文件及 `data/pl/manifest-source-v2.json` 供追溯，实际共 732 个文件（732 MiB）；旧缓存不参与当前显示。未打包的其他实验室数据仍按需读取固定上游版本。`python3 scripts/cache-data.py --all-sample` 校验并补齐完整样品。注册表保留旧 xH 路径别名，文件数量按实际文件去重。
- 基础实验室的 CPU LRU 缓存最多 8 个数据体；辉光样品另保留当前物理场的完整序列和四个梯度体。GPU 只保留当前数据体和所需梯度，复用纹理。交互时降低采样和画布分辨率，静止恢复；暂停时没有持续空转渲染，没有时间插值。
- 每次首次载入均检查字节数、SHA-256、有限性、物理范围（xH 为 [0,1]、密度 δ ≥ −1）和 min/max/mean。亮温保留正负号；未通过的文件不会显示。

## 三种效果

1. 基础显示：发射—吸收式前向合成；根据光线步长修正显示不透明度。
2. 结构强调：中心差分估算场梯度，以轻度漫反射光照增加深度线索。
3. 柔和深度：弱梯度光照结合四步短程方向体阴影；不是完整多次散射或物理再电离辐射输运。

三种效果共享当前物理量的固定色表、同一份 Float32 数据和完全相同的透明度权重。色标为 xH [0,1]、δ [−1,20]、亮温 [−150,40] mK；亮温零值使用暖白，吸收为蓝、发射为红。探针始终显示未变换原值与当前盒长对应的坐标。GPU 在插值原始线性值之后做显示映射。切换物理量会保留各场的自定义曲线；亮温默认按离零值的幅度控制显示权重。

基础模式是本实验实现的无光照对照，不承诺与线上 Viewer 像素相同。体渲染采用空间三线性插值；不支持浮点线性纹理过滤时使用手动插值。原值切片不作插值。

“中性区域 / 电离区域 / 过渡区间 / 自定义曲线”只改变显示权重。自定义曲线支持最多 16 个控制点，CPU 与 GPU 共用同一分段线性定义；切回预设时保留上次自定义曲线。原始过渡区间采用 Gaussian 权重，点击“编辑这条曲线”会转换成保留峰值的线性近似，并显示提示。

直方图始终包含完整网格，采用 log(1 + count) 柱高；红线为 [0, 1] 显示权重，横轴显示当前物理单位。全盒平均值不随裁切或权重改变。

三维切片经过实际单元中心，使用 `texelFetch` 读取公开 64³ 原值，不做平面内插值或光照。切片以固定 0.68 显示不透明度与体数据按射线深度合成，因此其屏幕颜色会受前后内容遮挡；定量读数以二维切片和探针为准。三维切片独立于体显示权重，权重全零时仍可查看。

三色切片轮廓和白色探针是可透视的定位辅助线，Z 裁切会同步裁剪这些辅助线。点击三维切片选择射线上最近的已开启平面，不是体表面拾取；多个平面开启时建议切换到单平面以精确定位。二维切片和探针仍可访问完整网格，并提示探针是否超出三维裁切范围。

相近平均 xH 模式选择最近的真实快照，因此 PL、BT 红移可能不同且平均 xH 不完全相等。相同红移模式按 a 选择对应帧。相同随机种子不证明相位匹配，不进行逐体素差分。

## 操作

- 拖动三维视图旋转，滚轮缩放；聚焦画布后方向键旋转，`+` / `-` 缩放，Home 重置。
- 点击任意切片，三个切片联动至同一网格位置；聚焦切片后方向键移动平面内探针，PageUp / PageDown 移动切片。
- “原值定位”面板中可用 X/Y/Z 滑块逐层查看，在三维视图开启单个或三个切片平面，点击平面联动探针。指针移动超过 4 CSS 像素才旋转，避免点选时误转视角。
- “可见度曲线”面板点击“编辑这条曲线”，可拖动控制点、双击添加，或用数值输入和键盘调整。端点固定 xH，只改变权重；最多 16 个控制点。
- 固定底栏提供模型、快照、阶段预设、显示权重、光照与 Z 裁切。
- 数据集与物理量在底栏选择。0.8 / 0.5 / 0.2 阶段按钮始终按平均 xH 选择，当前物理量的读数随所选真实快照更新。未发布的场禁用；切换数据集若不支持当前场，会明确提示切回 xH。
- WebGL2 不可用或丢失时保留 CPU 原值切片；数据错误会明确显示，不替换成模拟噪声。

## 切片库

`atlas.html` 接入仓库现有 55 组 BPL 与 32 组 PL 参考，各 32 个真实红移、256²、五种物理场，总计 13,920 张数值切片。支持全部模型选择、匹配 PL 并排、五场切换、红移逐帧/播放及双侧联动探针。这里是不同红移的 lightcone 横截面，不进行体重建。

清单 JSON 与 `.slices.bin` 均核对来源索引中的 SHA-256。浏览器只解压当前场，缓存最多两个模型和各自最近两个字段；每个红移切换不重新下载。亮温按 0.1 mK 解码，密度按各模型记录的步长、电离率按 1/32767 解码；Ts/Tk 将量化 log10(K) 还原为 K。

默认色标为本帧两侧数据的共同范围，可切换到跨模型固定范围以比较不同选择；电离率始终 [0,1]。Ts/Tk 使用对数色标；亮温共同范围包含零，零值为暖白。探针为量化后的物理值，原始范围、均值和色标饱和比例均明确显示。保留导出行列方向，从左上角 [0,0] 起，不推断天球方向或宣称相位匹配。

## 设计与参考

视觉采用大幅 21cm 字标、真实红移数字和深色观测舞台，保留低饱和红黄蓝坐标信号。首屏优先展示数据，底部控制台默认收起，可随时展开调参；三维色标固定在舞台内，切片库的对照图与中央红移保持同步。界面不自动播放或旋转数据。

三维数据占据首屏主要空间，右侧提供可核验的原值切片与分布，底部固定调参。暖白 `#F1F0E9`、炭灰 `#24292B` 与低饱和红 `#B84B3E`、黄 `#D6A62E`、蓝 `#4D8F9C` 用于界面；数据色表单独固定。字体使用本机 Avenir Next / 苹方，无外部字体请求。避免自动演出与与数据无关的装饰动画。

算法参考：[NVIDIA GPU Gems 39](https://developer.nvidia.com/gpugems/gpugems/part-vi-beyond-triangles/chapter-39-volume-rendering-techniques)、[Kitware 体渲染光照](https://www.kitware.com/cinematic-volume-rendering/)、[VolView 透明度编辑](https://kitware.github.io/VolView/rendering.html)。
