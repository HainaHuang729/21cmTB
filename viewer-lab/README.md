# 21cm 三维 Viewer

独立运行的最终三维版本，使用真实 21cmFAST 数据。界面采用个人网页的冷雾蓝灰风格，支持红移播放、折叠调参和全屏。没有构建步骤或第三方运行依赖，未接入仓库主网页。

## 运行

在此目录执行 `npm start`，打开 `http://127.0.0.1:8766/`。首页统一进入 `cavity.html`，保留地址中的 `model`、`field`、`z` 参数；旧三维实验页面和设计预览已移除。

也可以使用任意静态服务器，通过 localhost 或 HTTPS 访问。数据 SHA-256 校验依赖安全上下文，不能直接双击 HTML 文件运行。

- 三维：`cavity.html?model=pl&field=brightness_temperature&z=6`
- 密度：`cavity.html?model=pl&field=density&z=6`
- 二维切片库：`atlas.html`

## 操作与全屏

页头选择 PL / BT 模型和中性氢、密度、亮温。切换物理场时保持相同真实红移，并记住各模型各场的显示参数；不宣称模型之间逐体素相位匹配。

拖动三维画面旋转，滚轮缩放。聚焦画布后，方向键旋转，`+` / `-` 缩放，Home 重置。密度的“全盒 / 近看”只改变相机距离，保留红移与阈值。三维画面占满可用宽度，不附带二维切片或侧栏。左上角显示当前已载入快照的真实红移、网格与全盒原值均值；均值不受光照、剖切或显示阈值影响。

画面右上角“全屏”将三维画面与原有控制台一起放大。全屏内可拖动红移、上一帧/下一帧、播放/暂停、调整帧间隔，以及展开详细参数。点击“退出全屏”或按 Esc 返回；切换不重建播放器、不重置参数或相机。支持标准和 WebKit 全屏接口，受限的嵌入浏览器使用铺满窗口的布局。

红移滑块、帧序号、播放/暂停、逐帧切换与帧间隔直接放在三维画面底部，全屏时保持相同位置。页面底部只保留显示参数、重置视图与折叠按钮，宽屏时并排显示；不显示标题、标语、缓存计数和进度。后台预载与缓存照常运行，预载失败时出现重试按钮。右侧“展开参数 / 收起参数”支持鼠标和键盘，收起不会打断播放。折叠偏好在本地保存，刷新后恢复；浏览器禁用偏好存储时仍可正常折叠。隐藏参数不进入键盘焦点顺序。画布按控制台实际高度调整，矮窗口中的详细参数可滚动；短画布自动精简顶部附加读数，保留红移与播放。渲染与数据约定见本文后续章节。

界面沿用个人网页 `personal-archive` 的浅色主题：背景 `#edf2f5`、面板 `#e2eaf0`、文字 `#182e3b`、次级文字 `#526d7d`、细线 `#c0d0db`、操作色 `#356b83`。本地 Jost / IBM Plex Mono 字体及 SIL 授权、来源保存在 `assets/fonts/`。三维材质和数据色表独立于界面主题。

## 红移与缓存

PL / BT 各有 85 个真实红移位置，按时间顺序从高红移到低红移排列。滑块显示实际 z 与帧序号，没有时间插值，也不是等宇宙时间间隔。播放间隔可选 0.06、0.12、0.25、0.6、1.2 秒，默认 0.12 秒。

首次进入先准备当前场序列，再后台缓存其他模型与物理场。点击播放会等待当前序列校验完毕，等待时可取消。暂停取消尚未完成的显示切换，后台缓存继续；拖动红移、切换物理场或隐藏页面会停止播放。末帧自动停止，“重播”从首帧开始。计时会扣除当前帧读取与绘制所用时间，避免每帧额外累加一个完整等待间隔；超时后从实际帧起点重新计时，不跳过真实红移或突发追赶。下一次推进至少等待当前画布的动画帧提交。

当前发布 170 个 xH、170 个密度和 153 个亮温数据体，共 493 个、1,088 MiB。`python3 scripts/cache-data.py --all-sample` 可补齐、校验和修复本地文件，支持中断后重跑。浏览器按固定版本及 SHA-256 保存字节，读回仍核对哈希、有限性、物理范围和 min/max/mean；损坏缓存删除后重读来源。只有通过校验的帧才算准备完成。空间不足时回退本地文件并明确提示。

原值 CPU 缓存总预算 256 MiB：128³ 密度最多常驻 32 帧，完整 85 帧保存在持久缓存并准备临近帧，其他场最多保留八个 LRU 数据体。SHA-256、全体素有限性、范围与统计校验移入独立 Web Worker；持久缓存读回仍完整校验，损坏缓存仍删除后重读，工作线程不可用时回退相同校验函数。

密度辉光直接对原标量求短距离差分，不读取预计算梯度，因此跳过原来每帧冗余的 128³ RGBA 梯度计算和 32 MiB 上传；首次进入该分支时绑定完整的 1³ 占位采样器。其他场仍由 Web Worker 预计算接下来两帧梯度，只保留最近四个（64³ 时最多 16 MiB）。GPU 复用纹理，暂停后没有持续空转渲染。

播放时画布像素比最高 1.25，并按约 110 万总像素预算限制；128³ 密度采样 512 步，64³ 场保持 280 步。暂停、末帧和停止播放时自动恢复原有精细配置：密度最高 2 倍像素比、640 步，其他场最高 1.5 倍、280 步。所有辉光着色器、阈值、色彩、材质、光照与 bloom 参数保持原样；原始 128³ 密度也不降分辨率。原版与优化版在同一密度快照（PL、z=6）、相机和画布尺寸下，暂停精细画面的 RGBA 像素哈希一致。

[播放优化实测与画面一致性记录](science/playback/validation.json)：本机缓存完成、579×703 CSS 画布下，同档位密度由约 6.1 提升到 8.3 帧/秒；0.06 秒档位约 15.8 帧/秒，全屏约 16.2 帧/秒。亮温与中性氢在新档位约 16.5 / 16.4 帧/秒，五轮均按序绘制完整 85 个快照。实际速度仍取决于设备与画布大小，记录的是绘制提交间隔，不是屏幕逐像素呈现时刻。

## 真实数据与修复记录

- PL 250 cMpc：三个场均发布完整 85 帧。源网格为 256³；全部密度经 2³ 体积平均为 128³，每格约 1.95 cMpc；xH / 亮温经 4³ 平均为 64³。
- BT 250 cMpc：当前网页 xH / 密度为完整 85 帧，亮温为 68 帧，均为 64³。亮温 z=24.865–17.841 的 17 帧暂缓发布：时间轴标红，三维画面清空，播放到缺口暂停，不补造、不复用旧图像，可跳到前后有效片段。
- BT、独立 100 cMpc 缓存及二维切片固定于上游 `7daaaca68ac6df4f9ccd95fbb1bbb16ecc042fc0`。PL 250 cMpc 使用修复后的独立固定版本，具体提交见 `data.js` 的 `REVISION`。原始 HDF5 与三维 Ts/Tk 保存在集群，网页没有伪造 Ts/Tk 三维重建。
- `data/` 注册 518 个经过校验的真实场文件（1,113 MiB），其中 493 个用于最终三维 Viewer。另保留被替代的 PL 数据和清单用于科学追溯，实际共 817 个原值文件（1,412 MiB）；历史数据不参与当前显示。此次界面收束没有删除模拟数据或校验凭据。

## 渲染约定

最终界面只展示当前辉光版本。所有颜色、灯光和不透明度用于辨认结构，不表示真实发射光度、电流或已解析的物理前沿。原始标量没有锐化，没有添加人工粒子、恒星、几何连线或拓扑纤维骨架。

xH：真实标量三线性重建后射线求交，五次二分细化，梯度控制薄界面与窄值带亮度。均匀场不会出现虚构的发光前沿。阴影使用局部采样近似，不是辐射输运。

密度：插值原始 δ 后用 `log(1 + max(δ,0)) / log(4)` 作显示映射。青色层强调较弱密度界面，金色层标出高密节点；节点阈值始终为 `max(3δ, δ+0.8)`，默认纤维 δ=0.4、节点 δ=1.2，跨红移不自动归一化。两层按射线顺序合成，法线由 ±0.45 格处原标量差分计算；节点正视不透明度 4.5%、掠射最高 44.5%，退出界面再乘 0.3，最多合成 16 次交叉。没有低密背景或高密核心体积填充，默认光晕为 0。128³ 静止时采样 640 步，设备支持时最高 2 倍画布像素比。

亮温：蓝色为负亮温吸收，橙红为正亮温发射，零值透明。阈值以 `|δTb|` 的 mK 原值输入，梯度按符号修正，原始缓冲和统计不变。三维画面保留吸收/发射图例；全盒均值直接读取原值。

辉光采用 HDR 场景、选择性亮部提取、四分之一尺寸横纵高斯模糊与 ACES 近似色调映射；不支持浮点颜色缓冲时使用 RGBA8 回退。只对亮部添加光晕，不模糊源画面。WebGL2 不可用或丢失时显示错误，不替换成模拟噪声。

## 二维切片库

`atlas.html` 是独立的二维数据工具，包含 55 组 BPL 与 32 组 PL 参考，各 32 个红移、256²、五个物理场，共 13,920 张数值切片。支持模型选择、匹配 PL 并排、物理场切换、红移播放与双侧联动探针；这些是不同红移的 lightcone 横截面，不能拼为同一时刻的三维盒子。

本地 `atlas-data` 符号链接指向仓库已有 `../web_data`，不复制约 1 GB 数据。首次克隆后可执行 `ln -s ../web_data atlas-data`。仓库子路径部署直接复用 `../web_data/`，本地均不可用时回退固定上游公开文件。

清单与 `.slices.bin` 均核对 SHA-256，每次只解压当前场；亮温按 0.1 mK、电离率按 1/32767、密度按清单线性步长解码，Ts/Tk 从量化 log10(K) 还原。探针读取量化原值，温度为对数色标，其余线性；超出色标时报告饱和比例。沿用导出行列顺序，不推断天球方向或宣称相位匹配。

## 校验

Node.js 22 或更新版本下运行 `npm test`。现有测试覆盖文件哈希与统计、真实场范围、阶段选择、播放器异步顺序与暂停、缓存修复及预算、梯度工作线程、坐标与切片拾取、透明度曲线，以及真实五场切片的解压和异常数据拒绝。切片测试读取仓库已有 `web_data/`。全屏、Esc、红移操作、播放连续性、折叠与窄屏布局通过真实浏览器检查。
