Park / PL · Combined comparison

The latest two-model overlay combines the four-parameter corner plot and best-fit luminosity functions in one figure.

Red solid: PL with Park settings; Blue dashed: PL with the current HST+JWST data and MUV > −20. Both use PL cosmology and are normalized separately. This is not a BPL–PL comparison.

Park uses 27 HST points at z = 6, 7, 8, 10; the current PL analysis uses 34 HST+JWST points at z = 6, 7, 8, 9, 10. The Mturn and t★ priors also differ, so differences cannot be attributed solely to the observational data.

Park: 15000 stored steps; current PL: 30000 stored steps. Each uses 32 walkers × 2 ensembles. Neither has passed the convergence checks (maximum R̂ ≈ 2.07 for Park and ≈ 2.15 for PL). These are exploratory sampling results, not final parameter constraints. Snapshot: 2026-09-18.
